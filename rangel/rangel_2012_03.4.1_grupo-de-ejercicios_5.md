#### Ejercicio 1

**Una moneda se lanza tres veces seguidas. Recibe \$100 por cada cara (C) que aparezca y \$25 adicionales por cada dos caras seguidas que salgan (por ejemplo, CCC incluye dos conjuntos de CC). Sin embargo, debe pagar \$110 por cada águila (A) que salga. Tiene la opción de aceptar jugar o no.**
a) Dibuje el árbol de decisión para el juego.  
b) ¿Estaría dispuesto a participar en el juego?  

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | El jugador potencial. |
| **Acciones** | $a_1$: jugar; $a_2$: no jugar. |
| **Estados de la naturaleza** | Los 8 resultados posibles del lanzamiento de tres monedas: $\theta_1 = CCC$, $\theta_2 = CCA$, $\theta_3 = CAC$, $\theta_4 = ACC$, $\theta_5 = CAA$, $\theta_6 = ACA$, $\theta_7 = AAC$, $\theta_8 = AAA$. |
| **Probabilidades** | $p(\theta_i) = 1/8$ para todo $i$ (moneda justa, lanzamientos independientes). |

##### Construcción de la matriz de consecuencias

El pago asociado a cada resultado se calcula con la fórmula:

$$\text{Pago} = 100 \cdot (\text{número de C}) + 25 \cdot (\text{número de pares CC consecutivos}) - 110 \cdot (\text{número de A})$$

| Estado $\theta_i$ | Resultado | C | Pares CC | A | Pago (\$) |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $\theta_1$ | CCC | 3 | 2 | 0 | $300 + 50 - 0 = 350$ |
| $\theta_2$ | CCA | 2 | 1 | 1 | $200 + 25 - 110 = 115$ |
| $\theta_3$ | CAC | 2 | 0 | 1 | $200 + 0 - 110 = 90$ |
| $\theta_4$ | ACC | 2 | 1 | 1 | $200 + 25 - 110 = 115$ |
| $\theta_5$ | CAA | 1 | 0 | 2 | $100 + 0 - 220 = -120$ |
| $\theta_6$ | ACA | 1 | 0 | 2 | $100 + 0 - 220 = -120$ |
| $\theta_7$ | AAC | 1 | 0 | 2 | $100 + 0 - 220 = -120$ |
| $\theta_8$ | AAA | 0 | 0 | 3 | $0 + 0 - 330 = -330$ |

**Matriz de consecuencias** (filas = $\theta_i$, columnas = $a_j$):

| $\theta_i$ | $a_1$ (jugar) | $a_2$ (no jugar) |
| :---: | :---: | :---: |
| $\theta_1$ (1/8) | 350 | 0 |
| $\theta_2$ (1/8) | 115 | 0 |
| $\theta_3$ (1/8) | 90 | 0 |
| $\theta_4$ (1/8) | 115 | 0 |
| $\theta_5$ (1/8) | -120 | 0 |
| $\theta_6$ (1/8) | -120 | 0 |
| $\theta_7$ (1/8) | -120 | 0 |
| $\theta_8$ (1/8) | -330 | 0 |

##### Cálculo del VEM

$$VEM(a_1) = \frac{1}{8}*350 + \frac{1}{8}*115 + \frac{1}{8}*90 + \frac{1}{8}*115 - \frac{1}{8}*120 - \frac{1}{8}*120 - \frac{1}{8}*120 - \frac{1}{8}*330) = \frac{1}{8} * (350 + 115 + 90 + 115 - 120 - 120 - 120 - 330)$$
$$VEM(a_1) = \frac{1}{8}(670 - 690) = \frac{-20}{8} = -\$2.50$$

$$VEM(a_2) = 0$$

##### Dominación y decisión

La acción $a_2$ (no jugar) **domina débilmente** a $a_1$ en el sentido de que su VEM es mayor. No existe dominancia estricta estado por estado, pero el criterio del VEM es claro.

> **Decisión:** $VEM(\text{jugar}) = -\$2.50 < VEM(\text{no jugar}) = \$0$. **No conviene jugar.**

#### Ejercicio 2

**Usted tiene la oportunidad de participar en uno de dos negocios que van a establecerse. En el primero ($A_1$), si se tiene éxito obtendría una ganancia de \$100,000; si fracasa perderá \$100,000. En el segundo ($A_2$), si tiene éxito ganará \$10,000 y si fracasa le costará \$10,000.** 

a) Dibuje un diagrama de árbol de decisión para ambas situaciones.  
b) Encuentre la mejor decisión de acuerdo con los criterios de decisión bajo completa incertidumbre.  
c) Si $p$ es la probabilidad que asigna al evento "éxito", ¿bajo qué condiciones preferiría usted participar en $A_1$ o en $A_2$ y por qué?  
d) Utilizando pesos como variable aleatoria, represente los resultados como una distribución de probabilidad para $p=0.25$ y para $p=0.75$ y considere nuevamente su elección. ¿Cómo definiría el riesgo?  

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | El inversionista. |
| **Acciones** | $a_1$: participar en $A_1$; $a_2$: participar en $A_2$. |
| **Estados de la naturaleza** | $\theta_1$: éxito; $\theta_2$: fracaso. |
| **Probabilidades** | $p(\theta_1) = p$, $p(\theta_2) = 1 - p$ (incógnitas en los incisos b y c). |

##### Matriz de consecuencias

| $\theta_i$ | $a_1$ (negocio $A_1$) | $a_2$ (negocio $A_2$) |
| :---: | :---: | :---: |
| $\theta_1$ (éxito) | 100,000 | 10,000 |
| $\theta_2$ (fracaso) | -100,000 | -10,000 |

##### Inciso b — Criterios bajo incertidumbre completa

Al no conocerse las probabilidades, se aplican los criterios clásicos:

**Maximin (criterio Wald):** Se elige la acción cuyo peor resultado sea el mejor.
- $\min(a_1) = -100,000$
- $\min(a_2) = -10,000$
- **Mejor:** $a_2$

**Maximax (optimista):** Se elige la acción cuyo mejor resultado sea el mayor.
- $\max(a_1) = 100,000$
- $\max(a_2) = 10,000$
- **Mejor:** $a_1$

**Hurwicz (coeficiente $\alpha = 0.5$ por defecto):**
- $H(a_1) = 0.5(100,000) + 0.5(-100,000) = 0$
- $H(a_2) = 0.5(10,000) + 0.5(-10,000) = 0$
- Empate. Con $\alpha > 0.5$ (optimista): $a_1$; con $\alpha < 0.5$ (pesimista): $a_2$.

**Savage (minimax regret):** Matriz de arrepentimiento:

| $\theta_i$ | $a_1$ | $a_2$ |
| :---: | :---: | :---: |
| $\theta_1$ | 0 | 90,000 |
| $\theta_2$ | 90,000 | 0 |

- $\max \text{arrepentimiento}(a_1) = 90,000$
- $\max \text{arrepentimiento}(a_2) = 90,000$
- **Empate:** $a_1$ o $a_2$.

**Laplace (equiprobabilidad):**
- $L(a_1) = 0.5(100,000) + 0.5(-100,000) = 0$
- $L(a_2) = 0.5(10,000) + 0.5(-10,000) = 0$
- **Empate:** $a_1$ o $a_2$.

##### Inciso c — Análisis de sensibilidad en función de $p$

$$VEM(a_1) = 100,000\,p + (-100,000)(1-p) = 200,000\,p - 100,000$$
$$VEM(a_2) = 10,000\,p + (-10,000)(1-p) = 20,000\,p - 10,000$$

**Condición de preferencia:**

$$VEM(a_1) > VEM(a_2) \iff 180,000\,p > 90,000 \iff p > 0.5$$

**Reglas de decisión:**
- Si $p < 0.5$: ambos VEM son negativos; lo mejor es **no participar**.
- Si $p = 0.5$: ambos VEM son cero; indiferencia.
- Si $p > 0.5$: ambos VEM son positivos; se elige entre $a_1$ y $a_2$ según la **tolerancia al riesgo**.

##### Inciso d — Perfiles de riesgo

**Para $p = 0.25$:**

| Variable aleatoria $X$ | $a_1$ | $a_2$ |
| :---: | :---: | :---: |
| $x_1$ | 100,000 (p=0.25) | 10,000 (p=0.25) |
| $x_2$ | -100,000 (p=0.75) | -10,000 (p=0.75) |

- $VEM(a_1) = -50,000$; $VEM(a_2) = -5,000$.
- **Decisión:** No participar. El decisor es **evitador del riesgo** (prefiere no perder).

**Para $p = 0.75$:**

| Variable aleatoria $X$ | $a_1$ | $a_2$ |
| :---: | :---: | :---: |
| $x_1$ | 100,000 (p=0.75) | 10,000 (p=0.75) |
| $x_2$ | -100,000 (p=0.25) | -10,000 (p=0.25) |

- $VEM(a_1) = 50,000$; $VEM(a_2) = 5,000$.
- **Decisión:** Ambos son positivos. La varianza de $a_1$ es mucho mayor: $\text{Var}(a_1) = 0.75(100,000-50,000)^2 + 0.25(-100,000-50,000)^2 = 1.875 \times 10^9$.
- El decisor **evita el riesgo** si prefiere $a_2$ (menor dispersión); es **neutral al riesgo** si elige $a_1$ (mayor VEM).

#### Ejercicio 3

**La empresa que usted asesora desea invertir \$10,000 dólares en el mercado de valores comprando acciones de una de dos compañías: A o B. Las acciones de la compañía A representan un riesgo pero podrían dar un rendimiento del 50% sobre la inversión el siguiente año. Si las condiciones de la bolsa no son favorables, las acciones pueden perder 20% de su valor. La compañía B proporciona inversiones seguras con 15% de rendimiento en un mercado "a la alza" y sólo 5% en un mercado "a la baja". Todas las publicaciones que ha consultado predicen un 60% de posibilidades para un mercado "a la alza" y 40% para un mercado "a la baja".**

¿Dónde aconsejará a la empresa invertir el dinero?  

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | La empresa asesora. |
| **Acciones** | $a_1$: invertir en compañía A; $a_2$: invertir en compañía B. |
| **Estados de la naturaleza** | $\theta_1$: mercado a la alza; $\theta_2$: mercado a la baja. |
| **Probabilidades** | $p(\theta_1) = 0.60$, $p(\theta_2) = 0.40$. |

##### Matriz de consecuencias (rendimientos en dólares)

| $\theta_i$ | $a_1$ (compañía A) | $a_2$ (compañía B) |
| :---: | :---: | :---: |
| $\theta_1$ (alta, 0.60) | $+5,000$ | $+1,500$ |
| $\theta_2$ (baja, 0.40) | $-2,000$ | $+500$ |

##### Análisis de dominación

En $\theta_1$: $a_1$ paga más ($5,000 > 1,500$).
En $\theta_2$: $a_2$ paga más ($500 > -2,000$).
**No hay dominancia estricta.**

##### Cálculo del VEM

$$VEM(a_1) = 0.60(5,000) + 0.40(-2,000) = 3,000 - 800 = \$2,200$$
$$VEM(a_2) = 0.60(1,500) + 0.40(500) = 900 + 200 = \$1,100$$

##### Decisión

> **Decisión:** Invertir en las **acciones de la compañía A**, con un VEM de \$2,200.

#### Ejercicio 4

**Su empresa ha firmado un contrato con un banco por \$400,000 dólares para proveerle de chips "inteligentes" que integrarán a las nuevas tarjetas de crédito. Su Contador le reportó que los costos de administración, supervisión y de los materiales que requiere, serán de \$200,000 dólares.** 

**En cuanto al costo de la mano de obra, usted y el sindicato acordaron someter a un arbitraje la cuestión del nivel de habilidad que debe tener el operador de la máquina que la empresa tendrá que adquirir y que sólo es útil para fabricar este pedido. Si usted gana el arbitraje, la mano de obra tendrá un costo de \$8 dólares por hora; si el sindicato gana, el costo será de \$12 dólares por hora. Existen dos tipos de máquina en el mercado: la máquina A cuesta \$140,000 dólares y requerirá 4,000 horas-hombre para hacer todo el pedido. La máquina B cuesta \$100,000 dólares y necesitará 8,000 horas-hombre. Desafortunadamente usted debe decidir cuál de las dos máquinas comprará varias semanas antes de que pueda conocer el resultado del arbitraje.** 

**Las probabilidades a priori que su abogado ha establecido para el resultado del arbitraje son del 0.7 para un fallo de \$8 y de 0.3 para el de \$12; pero si el resultado es este último, es posible apelarlo con un costo de \$9,000 dólares, en cuyo caso ganar o perder la apelación tienen la misma probabilidad de ocurrir.** 

Siguiendo el criterio del VEM:

a) Construya el árbol de decisión del problema.  
b) ¿Qué máquina deberá comprar?  
c) Si el fallo del arbitraje lo obliga a pagar \$12/hora de trabajo, ¿deberá apelar a la resolución?  

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | La empresa manufacturera. |
| **Acciones** | $a_1$: comprar máquina A; $a_2$: comprar máquina B. |
| **Estados de la naturaleza** | $\theta_1$: fallo a \$8/hora (prob. 0.7); $\theta_2$: fallo a \$12/hora (prob. 0.3). |

##### Cálculo de las consecuencias (ganancias netas)

**Ingreso base:** \$400,000 - \$200,000 = \$200,000 (contracto menos costos fijos).

**Costo total por máquina y estado:**

| | Máquina A (\$140,000 + 4,000 h) | Máquina B (\$100,000 + 8,000 h) |
| :--- | :--- | :--- |
| $\theta_1$ (\$8/h) | $140,000 + 8 \times 4,000 = 172,000$ | $100,000 + 8 \times 8,000 = 164,000$ |
| $\theta_2$ (\$12/h) | $140,000 + 12 \times 4,000 = 188,000$ | $100,000 + 12 \times 8,000 = 196,000$ |

**Ganancia neta = 200,000 - costo total:**

##### Matriz de consecuencias

| $\theta_i$ | $a_1$ (máquina A) | $a_2$ (máquina B) |
| :---: | :---: | :---: |
| $\theta_1$ (\$8/h, p=0.7) | 28,000 | 36,000 |
| $\theta_2$ (\$12/h, p=0.3) | 12,000 | 4,000 |

##### Inciso b — Cálculo del VEM

$$VEM(a_1) = 0.7(28,000) + 0.3(12,000) = 19,600 + 3,600 = \$23,200$$
$$VEM(a_2) = 0.7(36,000) + 0.3(4,000) = 25,200 + 1,200 = \$26,400$$

> **Decisión b):** Comprar la **máquina B**, con VEM = \$26,400.

##### Inciso c — Análisis de la apelación

Si el fallo es \$12/hora y se adquirió la máquina B, la ganancia sin apelar es \$4,000.

**Opciones al apelar:**
- Ganar la apelación (p=0.5): costo de mano de obra cae a \$8/h. Ganancia = \$36,000 - \$9,000 (costo apelación) = \$27,000.
- Perder la apelación (p=0.5): se mantiene \$12/h. Ganancia = \$4,000 - \$9,000 = -\$5,000.

$$VEM(\text{apelar}) = 0.5(27,000) + 0.5(-5,000) = 13,500 - 2,500 = \$11,000$$

Como $VEM(\text{apelar}) = \$11,000 > \$4,000 = VEM(\text{no apelar})$:

> **Decisión c):** **Sí debe apelarse el fallo.**

#### Ejercicio 5

**Un cliente de una galería de arte está dispuesto a comprar la pintura "Ninfas" en \$50,000. La galería puede adquirir el cuadro hoy por \$40,000 o puede esperar un día y comprarlo mañana (si no se ha vendido) por \$30,000. También podría esperar otro día y comprarla, si aún está disponible, por \$26,000. Al final del tercer día la pintura no estará disponible para su venta. Cada día hay una probabilidad de 0.6 de que sea vendida.** 

¿Qué estrategia deberá seguir la galería para maximizar la ganancia esperada?

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | La galería de arte. |
| **Acciones (estrategias)** | $a_1$: comprar hoy; $a_2$: esperar a mañana, comprar si disponible; $a_3$: esperar al día 3, comprar si disponible; $a_4$: no comprar. |
| **Estados de la naturaleza** | $\theta_1$: se vende hoy (p=0.6); $\theta_2$: no se vende hoy, se vende mañana (p=0.4×0.6=0.24); $\theta_3$: no se vende hoy ni mañana, se vende día 3 (p=0.4×0.4×0.6=0.096); $\theta_4$: no se vende en los tres días (p=0.4×0.4×0.4=0.064). |

##### Resolución por inducción regresiva

Las ganancias potenciales si se compra son:
- Hoy: $50,000 - 40,000 = \$10,000$
- Mañana: $50,000 - 30,000 = \$20,000$
- Día 3: $50,000 - 26,000 = \$24,000$

**Paso 1 — Decisión en el día 3 (si el cuadro sigue disponible):**
- Comprar: ganancia = \$24,000
- No comprar: ganancia = \$0
- **Mejor:** comprar (VEM = \$24,000)

**Paso 2 — Decisión en el día 2 (si el cuadro sigue disponible):**
- Comprar: ganancia = \$20,000
- Esperar al día 3: con prob. 0.6 se vende mañana (ganancia \$0), con prob. 0.4 llega al día 3 (ganancia \$24,000).
  $$VEM(\text{esperar}) = 0.6(0) + 0.4(24,000) = \$9,600$$
- Como $\$20,000 > \$9,600$: **comprar en el día 2 si está disponible.**

**Paso 3 — Decisión en el día 1 (hoy):**
- Comprar hoy: ganancia = \$10,000
- Esperar: con prob. 0.6 se vende hoy (ganancia \$0), con prob. 0.4 llega al día 2 disponible (ganancia \$20,000).
  $$VEM(\text{esperar}) = 0.6(0) + 0.4(20,000) = \$8,000$$
- Como $\$10,000 > \$8,000$: **comprar hoy.**

> **Decisión:** Comprar el cuadro el **primer día**.

#### Ejercicio 6

**Un agricultor puede plantar maíz o frijol de soya. Las probabilidades de que los precios de la siguiente cosecha de estos productos aumenten, permanezcan iguales o desciendan son 0.25, 0.30 y 0.45, respectivamente. Si los precios aumentan, la cosecha de maíz producirá \$30,000 dólares netos y la soya \$10,000 dólares netos; si permanecen sin cambio apenas quedará "a mano", pero si los precios descienden, habrá pérdidas de \$35,000 para la cosecha de maíz y de \$5,000 para la de soya.** 

a) Represente el problema en un árbol de decisión.  
b) ¿Qué cosecha debe plantar el agricultor?  

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | El agricultor. |
| **Acciones** | $a_1$: plantar maíz; $a_2$: plantar soya. |
| **Estados de la naturaleza** | $\theta_1$: precios aumentan; $\theta_2$: precios se mantienen; $\theta_3$: precios descienden. |
| **Probabilidades** | $p(\theta_1) = 0.25$, $p(\theta_2) = 0.30$, $p(\theta_3) = 0.45$. |

##### Matriz de consecuencias

| $\theta_i$ | $a_1$ (maíz) | $a_2$ (soya) |
| :---: | :---: | :---: |
| $\theta_1$ (aumentan, 0.25) | 30,000 | 10,000 |
| $\theta_2$ (iguales, 0.30) | 0 | 0 |
| $\theta_3$ (descienden, 0.45) | -35,000 | -5,000 |

##### Dominación

En $\theta_1$: $a_1$ domina ($30,000 > 10,000$).
En $\theta_2$: empate ($0 = 0$).
En $\theta_3$: $a_2$ domina ($-5,000 > -35,000$).
**No hay dominancia global.**

##### Cálculo del VEM

$$VEM(a_1) = 0.25(30,000) + 0.30(0) + 0.45(-35,000) = 7,500 + 0 - 15,750 = -\$8,250$$
$$VEM(a_2) = 0.25(10,000) + 0.30(0) + 0.45(-5,000) = 2,500 + 0 - 2,250 = \$250$$

> **Decisión:** Plantar **frijol de soya**, con VEM = \$250.

#### Ejercicio 7

**La cadena de comida rápida FME está por lanzar a nivel nacional un nuevo tipo de comida. El departamento de investigación está convencido que será un gran éxito y lo quiere introducir de inmediato sin anuncios previos, mientras que el departamento de mercadotecnia quiere realizar una campaña intensiva de publicidad. Esta campaña costará \$100,000 dólares y, si tiene éxito, producirá \$850,000 de ganancia. Si la campaña no tiene éxito (y hay un 30% de posibilidad de ello), el ingreso se estima en sólo \$100,000. Si no se usa la publicidad, el ingreso se estima en \$400,000 con probabilidad de 0.8 si los clientes son receptivos y \$200,000 con probabilidad 0.2 si no lo son.** 

a) Dibuje el árbol de decisión.  
b) ¿Cuál curso de acción debe seguir FME para lanzar el producto?  

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | La cadena FME. |
| **Acciones** | $a_1$: lanzar con campaña publicitaria; $a_2$: lanzar sin campaña. |
| **Estados de la naturaleza** | Para $a_1$: $\theta_1$: campaña exitosa (p=0.7); $\theta_2$: campaña no exitosa (p=0.3). Para $a_2$: $\theta_3$: clientes receptivos (p=0.8); $\theta_4$: clientes no receptivos (p=0.2). |

##### Matriz de consecuencias (ganancias netas)

Para $a_1$: ganancia neta = ingreso - costo de campaña.
- $\theta_1$: $850,000 - 100,000 = \$750,000$
- $\theta_2$: $100,000 - 100,000 = \$0$

Para $a_2$: sin costo de campaña.
- $\theta_3$: $\$400,000$
- $\theta_4$: $\$200,000$

| $\theta_i$ | $a_1$ (con campaña) | $a_2$ (sin campaña) |
| :---: | :---: | :---: |
| éxito / receptivo | 750,000 (p=0.7) | 400,000 (p=0.8) |
| fracaso / no receptivo | 0 (p=0.3) | 200,000 (p=0.2) |

##### Cálculo del VEM

$$VEM(a_1) = 0.7(750,000) + 0.3(0) = \$525,000$$
$$VEM(a_2) = 0.8(400,000) + 0.2(200,000) = 320,000 + 40,000 = \$360,000$$

> **Decisión:** Realizar la **campaña de publicidad**, con VEM = \$525,000.

#### Ejercicio 8

**Dada la siguiente matriz de pago dada en miles de pesos,** 

represente el perfil de riesgo de cada acción utilizando "miles de pesos" como variable aleatoria:

| $\theta_i$ | $a_1$ | $a_2$ | $a_3$ | $a_4$ | $p(\theta_i)$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $\theta_1$ | -100 | 60 | 20 | -20 | 0.08 |
| $\theta_2$ | 160 | 80 | 60 | -100 | 0.10 |
| $\theta_3$ | 40 | 140 | -60 | -140 | 0.50 |
| $\theta_4$ | 200 | 40 | 20 | -40 | 0.12 |
| $\theta_5$ | 95 | 0 | 100 | 400 | 0.20 |

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | El tomador de decisiones. |
| **Acciones** | $a_1, a_2, a_3, a_4$. |
| **Estados de la naturaleza** | $\theta_1, \theta_2, \theta_3, \theta_4, \theta_5$ con probabilidades dadas. |

##### Cálculo del VEM

$$VEM(a_1) = 0.08(-100) + 0.10(160) + 0.50(40) + 0.12(200) + 0.20(95)$$
$$= -8 + 16 + 20 + 24 + 19 = 71$$

#### Ejercicio 9

**Usted tiene la oportunidad de apostar en el siguiente juego en un casino: se tira un dado dos veces, lo que puede producir uno de cuatro resultados: (1) las dos veces cae el mismo número par, (2) las dos veces cae el mismo número impar, (3) los resultados son par-impar o impar-par y (4) todos los demás resultados.** 

**Se le permite apostar a exactamente dos resultados con igual cantidad de dinero. Por ejemplo, puede apostar los mismos pesos a la pareja par (resultado 1) y a la pareja impar (resultado 2). El pago por cada peso que apueste es de \$2 para el primer resultado, \$1.95 para el segundo y tercer resultados y \$1.50 para el cuarto resultado.** 

a) Dibuje el árbol de decisión para el juego.  
b) ¿Cuáles dos resultados elegiría?  
c) ¿Considera que alguna vez podrá ganar en este juego?  

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | El apostador. |
| **Acciones** | Elegir 2 de los 4 resultados para apostar (6 combinaciones posibles). |
| **Estados de la naturaleza** | $\theta_1$: mismo par; $\theta_2$: mismo impar; $\theta_3$: par-impar o impar-par; $\theta_4$: otros. |

##### Cálculo de probabilidades

Espacio muestral: 36 resultados posibles al tirar dos dados.

- $\theta_1$ (mismo par): (2,2), (4,4), (6,6) → 3 casos → $p(\theta_1) = 3/36 = 1/12$
- $\theta_2$ (mismo impar): (1,1), (3,3), (5,5) → 3 casos → $p(\theta_2) = 3/36 = 1/12$
- $\theta_3$ (par-impar o impar-par): 3×3 + 3×3 = 18 casos → $p(\theta_3) = 18/36 = 1/2$
- $\theta_4$ (otros): 36 - 3 - 3 - 18 = 12 casos → $p(\theta_4) = 12/36 = 1/3$

##### Cálculo de ganancias netas por combinación

Si se apuesta \$1 a cada uno de dos resultados (inversión total = \$2):

| Resultado que ocurre | Pago recibido | Ganancia neta |
| :---: | :---: | :---: |
| $\theta_1$ | \$2 | \$0 |
| $\theta_2$ | \$1.95 | -\$0.05 |
| $\theta_3$ | \$1.95 | -\$0.05 |
| $\theta_4$ | \$1.50 | -\$0.50 |
| No ocurre ninguno | \$0 | -\$2.00 |

##### VEM de cada combinación

**Combinación (1,2):**
$$VEM = \frac{1}{12}(0) + \frac{1}{12}(-0.05) + \frac{1}{2}(-0.05) + \frac{1}{3}(-2)$$
$$= 0 - 0.0042 - 0.025 - 0.6667 = -\$0.6958$$

Espera, recalculo con la lógica correcta. Si apuesto a (1,2):
- Sale $\theta_1$: recibo \$2 (aposté \$1 al resultado 1 con pago \$2/\$). Ganancia = 2 - 2 = 0.
- Sale $\theta_2$: recibo \$1.95. Ganancia = 1.95 - 2 = -0.05.
- Sale $\theta_3$: recibo \$0. Ganancia = -2.
- Sale $\theta_4$: recibo \$0. Ganancia = -2.

$$VEM(1,2) = \frac{1}{12}(0) + \frac{1}{12}(-0.05) + \frac{1}{2}(-2) + \frac{1}{3}(-2)$$
$$= 0 - 0.0042 - 1 - 0.6667 = -\$1.67$$

**Combinación (1,3):**
- Sale $\theta_1$: recibo \$2. Ganancia = 0.
- Sale $\theta_2$: recibo \$0. Ganancia = -2.
- Sale $\theta_3$: recibo \$1.95. Ganancia = -0.05.
- Sale $\theta_4$: recibo \$0. Ganancia = -2.

$$VEM(1,3) = \frac{1}{12}(0) + \frac{1}{12}(-2) + \frac{1}{2}(-0.05) + \frac{1}{3}(-2)$$
$$= 0 - 0.1667 - 0.025 - 0.6667 = -\$0.858 \approx -\$0.86$$

**Combinación (1,4):**
- Sale $\theta_1$: 0; $\theta_2$: -2; $\theta_3$: -2; $\theta_4$: recibo 1.50, ganancia = -0.50.

$$VEM(1,4) = \frac{1}{12}(0) + \frac{1}{12}(-2) + \frac{1}{2}(-2) + \frac{1}{3}(-0.50)$$
$$= 0 - 0.1667 - 1 - 0.1667 = -\$1.33$$

**Combinación (2,3):**
- Sale $\theta_1$: -2; $\theta_2$: recibo 1.95, ganancia = -0.05; $\theta_3$: recibo 1.95, ganancia = -0.05; $\theta_4$: -2.

$$VEM(2,3) = \frac{1}{12}(-2) + \frac{1}{12}(-0.05) + \frac{1}{2}(-0.05) + \frac{1}{3}(-2)$$
$$= -0.1667 - 0.0042 - 0.025 - 0.6667 = -\$0.86$$

**Combinación (2,4):**
- Sale $\theta_1$: -2; $\theta_2$: -0.05; $\theta_3$: -2; $\theta_4$: -0.50.

$$VEM(2,4) = \frac{1}{12}(-2) + \frac{1}{12}(-0.05) + \frac{1}{2}(-2) + \frac{1}{3}(-0.50)$$
$$= -0.1667 - 0.0042 - 1 - 0.1667 = -\$1.34$$

**Combinación (3,4):**
- Sale $\theta_1$: -2; $\theta_2$: -2; $\theta_3$: -0.05; $\theta_4$: -0.50.

$$VEM(3,4) = \frac{1}{12}(-2) + \frac{1}{12}(-2) + \frac{1}{2}(-0.05) + \frac{1}{3}(-0.50)$$
$$= -0.1667 - 0.1667 - 0.025 - 0.1667 = -\$0.525 \approx -\$0.53$$

##### Resumen de VEM

| Combinación | VEM |
| :---: | :---: |
| (1,2) | -1.67 |
| (1,3) | -0.86 |
| (1,4) | -1.34 |
| (2,3) | -0.86 |
| (2,4) | -1.34 |
| (3,4) | -0.53 |

> **Decisión b):** Las mejores combinaciones son **(3,4)** y **(1,3)** (o (2,3)), con VEM = -\$0.53 y -\$0.86 respectivamente.
>
> **Decisión c):** Como **todos los VEM son negativos**, **no conviene jugar** en este casino. La casa siempre tiene ventaja.

#### Ejercicio 10

**Una empresa manufacturera produce lotes de artículos con 0.8%, 1%, 1.2% y 1.4% de defectuosos, con una probabilidad de 0.4, 0.3, 0.25 y 0.05, respectivamente. Tres clientes, A, B y C, firman contratos para recibir lotes con un máximo de 0.8%, 1.2% y 1.4% de defectuosos, respectivamente. La empresa será penalizada con \$1,000 dólares por punto porcentual si el porcentaje de defectuosos es mayor que el especificado en el contrato.**  

**Por otra parte, suministrar lotes con mayor calidad de la requerida le cuesta a la empresa \$500 dólares por punto porcentual.** 

Si los lotes no se inspeccionan antes del embarque:

a) Dibuje el árbol de decisión del problema.  
b) ¿Cuál de los tres clientes debe tener la prioridad más alta para recibir su orden apegada al contrato?  

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | La empresa manufacturera. |
| **Acciones** | $a_A$: asignar lote al cliente A (máx 0.8%); $a_B$: asignar al cliente B (máx 1.2%); $a_C$: asignar al cliente C (máx 1.4%). |
| **Estados de la naturaleza** | $\theta_1$: 0.8% defectuosos (p=0.4); $\theta_2$: 1% (p=0.3); $\theta_3$: 1.2% (p=0.25); $\theta_4$: 1.4% (p=0.05). |

##### Construcción de la matriz de consecuencias (costos)

**Regla de cálculo:**
- Si el lote excede el máximo del contrato: costo = \$1,000 × (puntos excedidos).
- Si el lote es mejor que el máximo: costo = \$500 × (puntos de diferencia).
- Si cumple exactamente: costo = \$0.

**Cliente A (máx 0.8%):**
- 0.8%: 0
- 1%: excede 0.2% → \$200
- 1.2%: excede 0.4% → \$400
- 1.4%: excede 0.6% → \$600

**Cliente B (máx 1.2%):**
- 0.8%: mejor en 0.4% → \$200
- 1%: mejor en 0.2% → \$100
- 1.2%: 0
- 1.4%: excede 0.2% → \$200

**Cliente C (máx 1.4%):**
- 0.8%: mejor en 0.6% → \$300
- 1%: mejor en 0.4% → \$200
- 1.2%: mejor en 0.2% → \$100
- 1.4%: 0

##### Matriz de consecuencias (costos esperados)

| $\theta_i$ | $a_A$ | $a_B$ | $a_C$ |
| :---: | :---: | :---: | :---: |
| $\theta_1$ (0.8%, p=0.4) | 0 | 200 | 300 |
| $\theta_2$ (1%, p=0.3) | 200 | 100 | 200 |
| $\theta_3$ (1.2%, p=0.25) | 400 | 0 | 100 |
| $\theta_4$ (1.4%, p=0.05) | 600 | 200 | 0 |

##### Cálculo del VEM (costo esperado)

$$VEM(a_A) = 0.4(0) + 0.3(200) + 0.25(400) + 0.05(600) = 0 + 60 + 100 + 30 = \$190$$
$$VEM(a_B) = 0.4(200) + 0.3(100) + 0.25(0) + 0.05(200) = 80 + 30 + 0 + 10 = \$120$$
$$VEM(a_C) = 0.4(300) + 0.3(200) + 0.25(100) + 0.05(0) = 120 + 60 + 25 + 0 = \$205$$

##### Análisis de la prioridad

Desde el punto de vista del **costo esperado**, el cliente B es el más conveniente (\$120). Sin embargo, la pregunta indaga por la **prioridad más alta para recibir la orden apegada al contrato**, lo cual se refiere a la **probabilidad de cumplimiento exacto**:

- Cliente A: $P(\text{cumple}) = P(0.8\%) = 0.4$
- Cliente B: $P(\text{cumple}) = P(\leq 1.2\%) = 0.95$
- Cliente C: $P(\text{cumple}) = P(\leq 1.4\%) = 1.0$

El cliente C tiene la **garantía de cumplimiento** del 100%, ya que su contrato permite hasta 1.4% de defectuosos, cubriendo todos los estados posibles del proceso productivo.

> **Decisión:** El **cliente C** debe tener la prioridad más alta, pues su contrato es el más flexible y garantiza el cumplimiento sin riesgo de penalización.

#### Ejercicio 11

**La empresa CAR, S.A. renta automóviles al precio de \$100 por día y cada contrato es exactamente de un día. A su vez, CAR, S.A. alquila los autos a la agencia mayorista "EN-Auto, S.A. de C.V." a un costo de \$70 por día, precio que incluye el mantenimiento de las unidades. El gerente de CAR, S.A. debe solicitar a la agencia mayorista el número de vehículos que necesitará alquilar cada día y entregar la solicitud, cuando menos, con una semana de anticipación.**

**Del registro de operaciones diarias de CAR, S.A. se encuentra el número de solicitudes de renta que ha tenido en los últimos 100 días:**

| Demanda | Número de días | Frecuencia relativa |
| :---: | :---: | :---: |
| 11 | 10 | 0.10 |
| 12 | 15 | 0.15 |
| 13 | 20 | 0.20 |
| 14 | 25 | 0.25 |
| 15 | 18 | 0.18 |
| 16 | 12 | 0.12 |

**Si se supone que el periodo de 100 días es una muestra representativa del comportamiento aleatorio pasado de la demanda, que no habrá cambios futuros en el comportamiento observado de ésta, y que el número de solicitudes para renta es completamente aleatorio,** 

encuentre el número de automóviles que CAR, S.A. deberá solicitar a "EN-Auto, S.A. de C.V." para maximizar su beneficio neto esperado.

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | El gerente de CAR, S.A. |
| **Acciones** | $a_j$: solicitar $j$ autos, con $j \in \{11, 12, 13, 14, 15, 16\}$. |
| **Estados de la naturaleza** | $\theta_i$: demanda real $i$, con $i \in \{11, 12, 13, 14, 15, 16\}$. |
| **Probabilidades** | Dadas por las frecuencias relativas observadas. |

##### Construcción de la matriz de consecuencias

**Fórmula del beneficio neto:**

$$\text{Beneficio}(D, S) = \min(D, S) \times 100 - S \times 70$$

donde $D$ es la demanda real y $S$ es la cantidad solicitada.

**Razonamiento:**
- Si $D \geq S$: todos los autos solicitados se rentán. Beneficio = $S \times 100 - S \times 70 = S \times 30$.
- Si $D < S$: solo se rentán $D$ autos, pero se pagan los $S$ solicitados. Beneficio = $D \times 100 - S \times 70$.

##### Matriz de pagos (beneficio en dólares)

| $D \backslash S$ | 11 | 12 | 13 | 14 | 15 | 16 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 11 (0.10) | 330 | 260 | 190 | 120 | 50 | -20 |
| 12 (0.15) | 330 | 360 | 290 | 220 | 150 | 80 |
| 13 (0.20) | 330 | 360 | 390 | 320 | 250 | 180 |
| 14 (0.25) | 330 | 360 | 390 | 420 | 350 | 280 |
| 15 (0.18) | 330 | 360 | 390 | 420 | 450 | 380 |
| 16 (0.12) | 330 | 360 | 390 | 420 | 450 | 480 |

##### Cálculo del VEM para cada acción

$$VEM(11) = 330$$

$$VEM(12) = 0.10(260) + 0.90(360) = 26 + 324 = 350$$

$$VEM(13) = 0.10(190) + 0.15(290) + 0.75(390) = 19 + 43.5 + 292.5 = 355$$

$$VEM(14) = 0.10(120) + 0.15(220) + 0.20(320) + 0.55(420) = 12 + 33 + 64 + 231 = 340$$

$$VEM(15) = 0.10(50) + 0.15(150) + 0.20(250) + 0.25(350) + 0.30(450)$$
$$= 5 + 22.5 + 50 + 87.5 + 135 = 300$$

$$VEM(16) = 0.10(-20) + 0.15(80) + 0.20(180) + 0.25(280) + 0.18(380) + 0.12(480)$$
$$= -2 + 12 + 36 + 70 + 68.4 + 57.6 = 242$$

##### Resumen

| Acción (S) | VEM |
| :---: | :---: |
| 11 | 330 |
| 12 | 350 |
| **13** | **355** |
| 14 | 340 |
| 15 | 300 |
| 16 | 242 |

> **Decisión:** Solicitar **13 unidades**, con un beneficio neto esperado máximo de **\$355**.

**Interpretación didáctica:** El VEM alcanza su máximo en $S = 13$ porque ese valor equilibra el costo de solicitar autos que no se rentarán (si la demanda es baja) contra el ingreso perdido por no tener autos disponibles (si la demanda es alta). La demanda esperada es $E[D] = 13.57$, pero la cantidad óptima es ligeramente menor debido a la asimetría del costo: cada auto no rentado representa una pérdida de \$70, mientras que cada auto faltante representa una ganancia perdida de \$30.

#### Ejercicio 12

**La corporación AR está considerando 3 opciones para manejar su base de datos: continuar con su personal; contratar una asesoría externa para que haga la administración, o una combinación de las dos anteriores. El costo anual de cada opción depende de la demanda futura como sigue:**

| Opciones / Demanda ($\theta_i$) | Personal propio | Asesor externo | Combinación de los dos | Probabilidades |
| :--- | :---: | :---: | :---: | :---: |
| Alta | 650 | 900 | 800 | 0.2 |
| Media | 650 | 600 | 650 | 0.5 |
| Baja | 600 | 300 | 500 | 0.3 |

a) ¿Qué alternativa de decisión minimiza el costo esperado de la operación de procesamiento de datos y cuál es el costo anual asociado con esa recomendación?  
b) Construya un perfil de riesgo para la decisión óptima.  
c) ¿Cuál es la probabilidad de que el costo exceda de \$700,000?  
d) Haga el análisis de sensibilidad considerando las acciones $a_1$ con $a_2$ y $a_2$ con $a_3$.  

##### Encuadre formal

| Elemento | Descripción |
| :--- | :--- |
| **Decisor** | La corporación AR. |
| **Acciones** | $a_1$: personal propio; $a_2$: asesor externo; $a_3$: combinación. |
| **Estados de la naturaleza** | $\theta_1$: demanda alta; $\theta_2$: demanda media; $\theta_3$: demanda baja. |
| **Probabilidades** | $p(\theta_1) = 0.2$, $p(\theta_2) = 0.5$, $p(\theta_3) = 0.3$. |

##### Matriz de consecuencias (costos en miles de dólares)

| $\theta_i$ | $a_1$ | $a_2$ | $a_3$ |
| :---: | :---: | :---: | :---: |
| $\theta_1$ (alta, 0.2) | 650 | 900 | 800 |
| $\theta_2$ (media, 0.5) | 650 | 600 | 650 |
| $\theta_3$ (baja, 0.3) | 600 | 300 | 500 |

##### Inciso a — Cálculo del VEM (costo esperado)

$$VEM(a_1) = 0.2(650) + 0.5(650) + 0.3(600) = 130 + 325 + 180 = \$635,000$$
$$VEM(a_2) = 0.2(900) + 0.5(600) + 0.3(300) = 180 + 300 + 90 = \$570,000$$
$$VEM(a_3) = 0.2(800) + 0.5(650) + 0.3(500) = 160 + 325 + 150 = \$635,000$$

> **Decisión a):** Contratar un **asesor externo**, con costo esperado mínimo de **\$570,000**.

##### Inciso b — Perfil de riesgo de la decisión óptima ($a_2$)

| Costo $X$ (miles) | 300 | 600 | 900 |
| :---: | :---: | :---: | :---: |
| $p(x)$ | 0.3 | 0.5 | 0.2 |

**Medidas de resumen:**
- Esperanza: $E[X] = 570$
- Varianza: $\text{Var}(X) = 0.3(300-570)^2 + 0.5(600-570)^2 + 0.2(900-570)^2 = 21,870 + 450 + 21,780 = 44,100$
- Desviación estándar: $\sigma = \sqrt{44,100} \approx 210$

##### Inciso c — Probabilidad de exceder \$700,000

$$P(X > 700) = P(X = 900) = p(\theta_1) = 0.2$$

> **Respuesta c):** La probabilidad es **0.2** (20%).

##### Inciso d — Análisis de sensibilidad

Sea $p = p(\theta_1)$ la probabilidad de demanda alta. Asumiendo que las probabilidades de demanda media y baja mantienen la proporción original $0.5:0.3 = 5:3$, se tiene:

$$p(\theta_2) = \frac{5}{8}(1-p), \quad p(\theta_3) = \frac{3}{8}(1-p)$$

**VEM en función de $p$:**

$$VEM(a_1) = 650p + 650 \cdot \frac{5}{8}(1-p) + 600 \cdot \frac{3}{8}(1-p)$$
$$= 650p + \frac{3250 + 1800}{8}(1-p) = 650p + 631.25(1-p) = 18.75p + 631.25$$

$$VEM(a_2) = 900p + 600 \cdot \frac{5}{8}(1-p) + 300 \cdot \frac{3}{8}(1-p)$$
$$= 900p + \frac{3000 + 900}{8}(1-p) = 900p + 487.5(1-p) = 412.5p + 487.5$$

$$VEM(a_3) = 800p + 650 \cdot \frac{5}{8}(1-p) + 500 \cdot \frac{3}{8}(1-p)$$
$$= 800p + \frac{3250 + 1500}{8}(1-p) = 800p + 593.75(1-p) = 206.25p + 593.75$$

**Comparación $a_1$ vs $a_2$:**

$$18.75p + 631.25 = 412.5p + 487.5 \implies 393.75p = 143.75 \implies p \approx 0.365$$

- Si $p < 0.365$: $a_2$ es mejor (asesor externo).
- Si $p > 0.365$: $a_1$ es mejor (personal propio).

**Comparación $a_2$ vs $a_3$:**

$$412.5p + 487.5 = 206.25p + 593.75 \implies 206.25p = 106.25 \implies p \approx 0.515$$

- Si $p < 0.515$: $a_3$ es mejor que $a_2$ en este tramo... pero revisando: para $p=0$, $VEM(a_3)=593.75 > VEM(a_2)=487.5$, así que $a_2$ es mejor.
- Si $p > 0.515$: $a_2$ es mejor que $a_3$.

**Regiones de optimalidad:**

| Rango de $p$ | Acción óptima |
| :---: | :---: |
| $p < 0.365$ | $a_2$ (asesor externo) |
| $0.365 < p < 0.515$ | $a_3$ (combinación) |
| $p > 0.515$ | $a_1$ (personal propio) |

> **Interpretación:** La decisión óptima es sensible a la probabilidad de demanda alta. Si esta probabilidad aumenta significativamente (por encima de 0.515), conviene invertir en personal propio; si es baja (menos de 0.365), lo mejor es externalizar; y en un rango intermedio, la combinación de ambas opciones es la más robusta.
